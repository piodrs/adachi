# adachi

A minimal fullscreen window manager for X11

## Key bindings

Press `Ctrl+t`, release it, then press:

- `c`: open `xterm`
- `!`: open `dmenu_run`
- `n` or `Space`: focus the next window
- `p`: focus the previous window
- `t` or `Tab`: focus the last window
- `0`–`9`: focus a window by index
- `k`: close the current window
- `q`: quit Adachi

Bindings are configured in `config.h`
